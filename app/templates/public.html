EMBOXA WEB

{% if locale == 'it' %}Come funziona il servizio{% else %}How the service works{% endif %}

{% if locale == 'it' %}Emboxa Web è un’applicazione multiutente per copiare caselle IMAP in archivi versionati, consultarli dal browser e portarli con sé tramite export.{% else %}Emboxa Web is a multi-user application that copies IMAP mailboxes into versioned archives, makes them browsable, and provides portable exports.{% endif %}

01

{% if locale == 'it' %}Connessione IMAP{% else %}IMAP connection{% endif %}

{% if locale == 'it' %}Aggiungi una casella con indirizzo, server, porta e credenziali. Il test di connessione individua gli errori prima del primo backup. Le credenziali persistenti sono cifrate a riposo.{% else %}Add a mailbox with its address, server, port, and credentials. Connection testing catches errors before the first backup. Persistent credentials are encrypted at rest.{% endif %}

02

{% if locale == 'it' %}Coda e versioni{% else %}Queue and versions{% endif %}

{% if locale == 'it' %}I backup entrano in una coda persistente con stato, percentuale ed ETA. Un’esecuzione completata crea una versione separata; retention e numero di versioni dipendono dal piano e dalle impostazioni.{% else %}Backups enter a persistent queue with status, percentage, and ETA. A completed run creates a separate version; retention and version count depend on plan and settings.{% endif %}

03

{% if locale == 'it' %}Archivio e ricerca{% else %}Archive and search{% endif %}

{% if locale == 'it' %}Sfoglia le cartelle originali, cerca tra i campi principali e i nomi degli allegati, apri i messaggi e passa da una versione all’altra senza ricreare il backup.{% else %}Browse original folders, search key fields and attachment names, open messages, and switch versions without rebuilding the backup.{% endif %}

04

{% if locale == 'it' %}Esportazione e importazione{% else %}Export and import{% endif %}

{% if locale == 'it' %}Gli export temporanei usano link autenticati e scadono automaticamente. Il formato EMBOXA conserva manifest e dati necessari alla verifica e al successivo reimport.{% else %}Temporary exports use authenticated links and expire automatically. The EMBOXA format keeps the manifest and data required for verification and later import.{% endif %}

05

{% if locale == 'it' %}Sicurezza operativa{% else %}Operational security{% endif %}

{% if locale == 'it' %}Sessioni protette, isolamento tra utenti, controlli di quota e chiavi separate proteggono l’accesso. Nessun sistema elimina però il rischio: usa password per app e conserva una copia indipendente degli export importanti.{% else %}Protected sessions, tenant isolation, quota checks, and separate keys protect access. No system removes all risk: use app passwords and keep an independent copy of important exports.{% endif %}
